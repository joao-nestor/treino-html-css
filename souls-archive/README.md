# Souls Wiki

Projeto de desenvolvimento de uma wiki dedicada aos jogos da franquia Souls, com o objetivo de reunir informações sobre os jogos, chefes, personagens, itens e outros elementos desse universo.

## Objetivo

Desenvolver um site inspirado em wikis de jogos, praticando conceitos de desenvolvimento web e construindo uma interface organizada, intuitiva e agradável para os usuários.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades planejadas

- [ ] Página inicial com apresentação do projeto.
- [ ] Navegação entre os jogos da franquia.
- [ ] Páginas dedicadas a chefes e personagens.
- [ ] Informações sobre armas, itens e equipamentos.
- [ ] Layout responsivo para diferentes tamanhos de tela.
- [ ] Melhorias de acessibilidade e navegação.

## Desenvolvimento

O projeto será desenvolvido gradualmente, começando pela estrutura HTML e pela estilização com CSS. Novas melhorias serão adicionadas conforme o aprendizado e a evolução do site.

## Status do projeto

Em desenvolvimento.

## Propósito educacional

Este projeto também serve como prática de HTML e CSS, permitindo aplicar conhecimentos de estruturação de páginas, estilização, layouts, espaçamento, cores e organização de código.

## Observações

Projeto independente e não oficial, criado com finalidade educacional e de estudo. Os direitos sobre as franquias, marcas e conteúdos relacionados pertencem aos seus respectivos proprietários.
